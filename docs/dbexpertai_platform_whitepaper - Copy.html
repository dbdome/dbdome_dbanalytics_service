How it works

One pipeline, five stages.

Every metric flows the same route — collected per-engine, analyzed for anomalies and threats, resolved against the taxonomy, surfaced as issues and incidents, then delivered as dashboards, reports, alerts, SIEM events and enforcement.

01

Collect

Vendor-aware collectors pull metrics, plans, config, audit & security signals on per-metric schedules.

02

Analyze

Anomaly detection (incl. ML autoencoders), threat & SQL-injection detection; each step records matched vs expected.

03

Root-cause

Matched steps roll up the taxonomy: steps → root causes → issues → areas → domains.

04

Surface

Issues (vertical decision trees) and Incidents (cross-cutting statistical + named-threat signatures).

05

Deliver

Dashboards, PDF/XLSX reports, email, SIEM forwarding, AI chat — and in-database enforcement.

The headline capability

Database Activity Monitoring, scored for compliance.

DAM is the platform's spine: continuous capture and analysis of live sessions, transactions and audit activity — privileged access, authentication, DDL, sensitive-data reads — rolled up into a weighted, per-regulation compliance score you can hand an auditor.

Continuous capture & analysis. Active-transaction and active-session analyzers, sensitive-column access tracking, and an audit feed land in monitoring.general_metric_metadata_results and the alert store — with excluded service logins filtered out at the source so alerts stay signal, not noise.

A DAM compliance score, not just a log. v_dam_compliance_scorecard computes ten risk-weighted control areas 0–100 over a trailing 30-day window; v_dam_regulation_score rolls them into a per-framework score plus an overall posture band.

One-click evidence. The DAM Compliance Report renders on demand — /dam_report → Print PDF (/api/print-dam) or Send by mail (/api/email-dam) — or on a weekly schedule, mapping every control to its PCI-DSS / HIPAA / SOX / GDPR / SOC 2 clause.

The differentiator

Diagnostic depth: symptom → cause → resolution.

Most tools stop at "here's an anomaly." dbexpert.ai walks authored decision trees over a curated taxonomy to take an operator from a symptom to the specific upstream root cause and the steps to fix it.

DOMAIN Performance
  └ ISSUE Query latency spike
    ├ step waits = ASYNC_NETWORK_IO? ✗
    ├ step plan regressed? ✓
    └ ROOT CAUSE · parameter-sniffing plan flip
      → RESOLUTION · recompile / plan guide

Detection steps carry matched-vs-expected; branching (on_match_action / on_no_match_action) routes to the next probe until a leaf root cause is reached, then a parallel resolution path is attached.

A knowledge core, not just rules

The taxonomy lives in a governed PostgreSQL schema — domains → areas → issues → root_causes → detection_paths → detection_steps, with parallel resolution paths and a customer-extensible signature layer for named threats (ransomware, worms, exfiltration, insider).

Deployment

One appliance. Yours, even offline.

The same product ships as hosted SaaS or a fully self-contained on-prem appliance — scheduler, web UI, reporting and email in a single binary, installable with nothing to phone home.

Self-contained

Single binary

Scheduler + FastAPI web UI + reporting + email in one PyInstaller build; bundles PostgreSQL and the SQL Server ODBC driver.

Any OS

Windows · Linux · macOS

Windows ISO, Linux x86_64 and macOS arm64 packages; registered as an auto-restarting service (NSSM / pywin32 / systemd).

Air-gapped

No internet required

Seed taxonomy restored at install; Ed25519-signed offline update bundles; a bootstrap token exchanged once for a local ingest token.

Agentless

Nothing on the DB host

Out-of-band collection over unified, encrypted vendor connections — no agent to install on the monitored databases.

Self-watching

Monitors itself

Appliance disk / CPU / memory / service checks raise the same alerts as the databases it protects.

Delivered

Dashboards → boardroom

Web dashboard & mobile PWA, executive Fleet-Health PDF, per-row Findings XLSX, ranked Triage Worklist, SIEM forwarding, and (SaaS) RAG-grounded AI chat.

Monitor, explain, prove, and enforce — without stitching six tools together.

dbexpert.ai unifies Database Activity Monitoring, a deep diagnostic taxonomy, compliance scoring and evidence, a database firewall, data protection and active threat response into one agentless, air-gap-capable appliance — enforcing inside the database, not in a proxy in front of it.
