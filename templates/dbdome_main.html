Where to go

Each destination opens its dashboard. Alerts and Incidents are the day-to-day views; Configuration is where the platform itself is set up.

⚠ Alerts The latest alert per server and root cause. Select one to see the detection result set, the security agent's verdict and the values that tripped the rule. › ⚑ Incidents The unresolved queue — open alerts awaiting triage, with the resolve control. This is the shift's work list. › ▤ Data activity monitoring Who is doing what: active transactions, unique users and the top users by volume. Establishes what normal looks like. › ⚙ Configuration Monitored servers, active detection rules by vendor and domain, reports, notification routing and scheduled processes. › ☰ Reports GRC and compliance packs, the DAM compliance report, alert and data-activity reports, and their schedules. › ☷ Settings Create and invite users, and review who has access to dbdome. ›
